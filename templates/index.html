About This Project

MNIST Digit Classifier is a machine learning web application that recognizes handwritten digits from 0 to 9 using a Convolutional Neural Network (CNN).

What is MNIST?

MNIST is a dataset containing handwritten digits from 0 to 9. Each image has a size of 28 × 28 pixels and is used widely for training and testing image classification models.

How Does the CNN Work?

The CNN learns visual patterns from handwritten digits. Convolutional layers extract important features, pooling reduces the feature size, and fully connected layers classify the digit.

Input Image → Convolution → Pooling → Classification → Prediction

Model Performance

The trained CNN achieves approximately 98% test accuracy on the MNIST dataset.

The application also displays the predicted digit's confidence and the probability distribution across all ten digits.
